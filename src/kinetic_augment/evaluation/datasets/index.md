# Evaluation datasets index

- `__init__.py` — Exports evaluation dataset base classes, WLASL adapters, and face training APIs.
- `base.py` — Defines the evaluation dataset interface and synthetic dataset.
- `face_features.py` — Converts versioned face archives into masked training samples and safely collates unnamed no-face blendshape streams.
- `wlasl.py` — Loads and preprocesses WLASL sign-language data.
- `index.md` — Index of evaluation dataset adapters and interfaces.
