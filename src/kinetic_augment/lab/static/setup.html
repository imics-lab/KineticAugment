Set up full mode

Back to the Lab

The shared zip shows a fixed grid of settings worked out ahead of time. Full mode runs the Lab on your own machine, so any knob can take any value, you can add your own videos, and saved settings go straight into the repository. It needs the licensed body-model files, which we cannot pass around, so you download those yourself.

Model files

FileState

1. Get the code and install it

git clone https://github.com/imics-lab/KineticAugment.git
cd KineticAugment
python -m venv .venv
source .venv/bin/activate
pip install -e '.[smplx,lab]'

Python 3.9 or newer.

2. Get the model files

Put them under models/ in the repository, or in any folder with the same layout (step 4 tells the Lab where). SMPL-X, MANO and FLAME are free for research but you have to register on each site first.

FileWhat it is forWhere from
smplx/SMPLX_NEUTRAL.npzthe body https://smpl-x.is.tue.mpg.de/
mano/MANO_LEFT.npz, mano/MANO_RIGHT.npzthe hands MANO comes with the SMPL-X download. Put MANO_LEFT.pkl and MANO_RIGHT.pkl in <repo>/models/mano, then run python scripts/convert_mano.py from the repository root (it always reads models/mano) to make these two files. If you keep your models somewhere else, convert in the repo first, then copy the two .npz files there.
mano/SMPL-X__FLAME_vertex_ids.npylinks the head to the face model already in the repository
flame/generic_model.pklthe face shape https://flame.is.tue.mpg.de/
flame/mediapipe_landmark_embedding.npzties MediaPipe face points to the face model https://github.com/Zielon/metrical-tracker/tree/master/flame/mediapipe
mediapipe/face_landmarker.taskreads the face out of a video run python scripts/download_models.py --face

To check what is still missing, run:

python scripts/download_models.py --check

3. Start the Lab

kinetic-lab

This opens http://127.0.0.1:8770 in your browser. The server only listens on your own machine. If the repository's models/ folder is already complete, it is used and you can skip step 4. Useful flags: --port, --clips-dir (default demo/round_trip/clips), --model-dir, --no-browser. Without the command on your path, python -m kinetic_augment.lab.cli does the same.

4. Tell the Lab where the models are

If the Lab shows this page with missing files, put the model folder path in the field above and press the button. The path is remembered in ~/.kinetic_lab/config.json, so you do this once. Opened from the zip, this page can only show the steps; run the Lab yourself and open it at http://127.0.0.1:8770/setup.html to use the field.

Then

Pick a clip and an augmentation, move the A and B markers on any knob, and the pane updates in about a second. "＋ add video" fits a new .mp4 (one to two minutes on a laptop). "Save" writes the setting to configs/viewer_saved/<name>.yaml. The details are in docs/augmentation-lab.md.
