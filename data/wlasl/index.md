# WLASL metadata index

- `WLASL_v0.3.json` — Official WLASL annotations (2000 glosses, video_id → gloss, signer, split). Not committed: download from https://raw.githubusercontent.com/dxli94/WLASL/master/start_kit/WLASL_v0.3.json (about 11 MB).
- `clip_glosses.csv` — One row per local clip: gloss, WLASL rank, signer, split, variation and whether it may be mirrored. Written by `scripts/map_clip_glosses.py`.
- `index.md` — This index.
